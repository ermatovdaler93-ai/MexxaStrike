# MEXXA STRIKE (Godot 4.3) — сборка 0.2: играбельный тир

Объединены Фаза 2 (меню), Фаза 3 (мобильное управление) и часть Фазы 4 (5 видов оружия),
плюс тестовая арена-тир. Боты с ИИ, LAN-мультиплеер, остальные карты и режимы — в следующих фазах.

## Как обновить репозиторий и собрать APK (Termux)
```
cd ~ && unzip -o ~/storage/downloads/MexxaStrike_Build02_Godot.zip
cd ~/MexxaStrikeGodot && ls -a
git add .
git -c user.name=me -c user.email=me@example.com commit -m "build 0.2 playable"
git push
```
(Если Git просит вход: Username `ermatovdaler93-ai`, Password — свежий токен; создать:
https://github.com/settings/tokens/new?scopes=repo,workflow&description=termux)
Затем на GitHub: Actions → «Build APK» → после зелёной галочки скачать `MexxaStrike-apk` из Artifacts.

## Как играть
- **Меню**: PLAY — сразу в тир; OFFLINE — выбрать число мишеней (3–10); SETTINGS — чувствительность и язык (EN/RU);
  WEAPONS — характеристики оружия; PROFILE — ник и статистика; LAN — заглушка (появится позже).
- **Цель**: за 2 минуты сбить как можно больше движущихся красных мишеней (после попаданий они возрождаются).
- **Управление** (горизонтальный экран):
  - левый большой палец в левой части экрана — джойстик движения (появляется под пальцем);
  - правая часть экрана — перетаскивание пальцем для обзора (можно и пальцем, который держит кнопку огня);
  - кнопки справа: FIRE, JUMP, CROUCH (переключатель), RELOAD, SWAP (следующее оружие);
  - кнопка MENU в правом верхнем углу; системная кнопка «Назад» тоже возвращает в меню.
- **Оружие**: MX-47 (штурмовая), MX-90 (SMG), MX-R4 (снайперская), MX-Eagle (пистолет), MX-12 (дробовик).
  Автоматическое оружие стреляет, пока держите кнопку; остальное — одно нажатие = один выстрел.

## Если собралось, но что-то не так
Пришлите: модель телефона, что именно не работает (меню, управление, стрельба) и, если приложение
вылетает, последние строки красного шага из Actions. Игра не проверялась на реальном устройстве
до вашего запуска, поэтому возможны мелкие ошибки.
